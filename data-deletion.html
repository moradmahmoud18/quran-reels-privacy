Quran Reels Manager - Data Deletion Instructions

Last updated: November 9, 2026

1. Your Right to Request Data Deletion

Users of Quran Reels Manager can request deletion of personal information associated with their use of the application.

2. How to Request Data Deletion

To request assistance with deleting your data, send an email to:

Email: morad1234m098765@gmail.com

Please use the subject: Quran Reels Manager - Data Deletion Request

Your request should include:

  • The application name: Quran Reels Manager.
  • A description of the data you want deleted.
  • Enough information to identify your request safely.

Never include your passwords, Telegram login codes, Facebook access tokens, or other authentication secrets.

3. What Data Can Be Deleted?

Depending on the request and the data involved, deletion may include:

  • Application settings and locally stored records.
  • Locally stored Telegram session information.
  • Locally stored Facebook authentication information.
  • Other application-related information that can be identified and deleted.

4. Local Data Removal

Users can remove locally stored application data by clearing the application's data through Android settings or uninstalling the application.

5. Third-Party Data

Quran Reels Manager does not control data independently stored by Telegram or Meta/Facebook. Users may need to contact those services or use their account settings to manage or delete information held by them.

Deleting application data does not automatically delete videos already published on Facebook or original messages and media stored in Telegram.

6. Request Processing

We will review deletion requests and respond by email. Additional information may be requested when reasonably necessary to verify and process a request safely.
